# Основы систем мобильной связи

Практические работы по курсу "Основы систем мобильной связи" (СибГУТИ). Каждая работа - это Jupyter-блокнот с расчётами на Python и отчёт в LaTeX.

## Структура репозитория

```
.
├── lab_N/              одна практическая работа (N - её номер)
│   ├── main.ipynb      блокнот с заданиями и решением
│   ├── report/         отчёт
│   │   ├── main.tex    исходник отчёта (XeLaTeX)
│   │   └── images/     графики и рисунки для отчёта
│   └── ...             методичка и входные файлы работы (записи, скриншоты и т.п.)
├── utils/              общий код, который используют все работы
├── justfile            команды для настройки окружения
├── requirements.txt    зависимости Python
└── README.md
```

Работы лежат в папках `lab_1`, `lab_2` и так далее и устроены одинаково. Код, который нужен нескольким работам, выносится в `utils/`, а не копируется между блокнотами.

## Запуск

Нужны Python 3 и [just](https://github.com/casey/just).

```
just setup
```

Команда создаёт виртуальное окружение `.venv` и ставит зависимости из `requirements.txt`. Дальше откройте нужный `lab_N/main.ipynb` и выберите ядро из `.venv`. Блокнот запускается из своей папки (`lab_N`).
